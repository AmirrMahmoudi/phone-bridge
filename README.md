# PhoneBridge (پل ارتباطی اندروید و آیفون)

یک راه‌حل کاملاً امن، آفلاین و اختصاصی برای انتقال تماس‌های صوتی و پیامک‌ها از گوشی اندرویدی (سیم‌کارت‌دار) به آیفون (بدون سیم‌کارت یا بدون رجیستری مانند آیفون ۱۷).

---

## 🎯 ویژگی‌های کلیدی

* **بدون نیاز به نصب Xcode یا Android Studio روی مک:** تمام خروجی‌ها (فایل‌های نصبی APK و IPA) به صورت خودکار توسط GitHub Actions در فضای ابری ساخته می‌شوند.
* **رابط کاربری بومی آیفون (Apple CallKit):** هنگام دریافت تماس در سیم‌کارت اندروید، صفحه تماس اصلی و بومی آیفون ظاهر می‌شود (حتی در حالت Lock Screen).
* **۱۰۰٪ آفلاین و مستقیم:** ارتباط بین دو گوشی از طریق بلوتوث مستقیم (Direct BLE) انجام می‌شود و هیچ سرور اینترنتی واسطی وجود ندارد.
* **انتقال پیامک‌ها و اعلان‌ها:** دریافت آنی پیام‌های کوتاه سیم‌کارت روی آیفون.

---

## 🚀 راهنمای سریع: گرفتن فایل‌های نصبی و اجرا

### گام ۱: ساخت ریپازیتوری در گیت‌هاب و ارسال کدها
1. در سایت [GitHub.com](https://github.com) یک ریپازیتوری جدید (می‌تواند Private یا Public باشد) به نام مثلاً `phone-bridge` بسازید.
2. در ترمینال مک‌بوک خود دستورات زیر را اجرا کنید:
   ```bash
   cd "phone-bridge"
   git remote add origin <لینک_ریپازیتوری_گیت‌هاب_شما>
   git push -u origin main
   ```

### گام ۲: دانلود فایل‌های آماده از گیت‌هاب
1. به صفحه ریپازیتوری خود در گیت‌هاب بروید و وارد تب **Actions** شوید.
2. مشاهده می‌کنید که بیلد خودکار شروع شده است.
3. پس از اتمام (حدود ۲ الی ۳ دقیقه)، وارد آخرین اجرا شوید و در بخش **Artifacts**:
   * فایل **`PhoneBridge-Android-APK`** را برای گوشی سامسونگ دانلود کنید.
   * فایل **`PhoneBridge-iOS-IPA`** را برای آیفون ۱۷ دانلود کنید.

---

### گام ۳: نصب روی گوشی سامسونگ (Android)
1. فایل APK دانلودشده را به گوشی سامسونگ خود بفرستید (از طریق تلگرام، کابل، یا بلوتوث) و آن را نصب کنید.
2. برنامه را باز کرده و:
   * تمام مجوزهای درخواستی (تماس، پیامک و بلوتوث) را تایید کنید.
   * گزینه **"تنظیم به عنوان سرویس تماس پیش‌فرض"** را بزنید تا سیستم اجازه پاسخگویی خودکار را بدهد.
   * دکمه **"شروع سرور بلوتوث"** را بزنید.

---

### گام ۴: نصب روی آیفون ۱۷ (iOS) بدون نیاز به Xcode
1. نرم‌افزار کم‌حجم و رایگان **[Sideloadly](https://sideloadly.io/)** (حدود ۵۰ مگابایت) را روی مک‌بوک خود دانلود و باز کنید.
2. آیفون ۱۷ را با کابل به مک‌بوک وصل کنید.
3. فایل **`PhoneBridge.ipa`** (دانلودشده از گیت‌هاب) را با موس بکشید و داخل پنجره Sideloadly رها کنید (Drag & Drop).
4. ایمیل اپل‌آیدی (Apple ID) خود را در کادر مربوطه وارد کرده و دکمه **Start** را بزنید.
5. پس از چند ثانیه، اپلیکیشن مستقیماً روی آیفون ۱۷ شما نصب می‌شود!
6. *نکته آیفون:* در اولین بار باز کردن اپ، در آیفون به مسیر:
   `Settings > General > VPN & Device Management`
   بروید و روی ایمیل اپل‌آیدی خود بزنید و گزینه **Trust** را تایید کنید.

## 🏗 ساختار پروژه

```text
phone-bridge/
├── .github/workflows/build.yml # پایپ‌لاین بیلد خودکار ابری (Android APK & iOS IPA)
├── protocol/
│   └── SPECIFICATION.md       # مشخصات پکت‌های بلوتوث، کدهای JSON و UUIDها
├── ios-client/                # کلاینت آیفون (Swift, CallKit, CoreBluetooth)
│   └── PhoneBridge/
│       ├── project.yml        # پیکربندی کامپایل بدون نیاز به محیط گرافیکی
│       ├── Info.plist         # مجوزهای پس‌زمینه VoIP و بلوتوث
│       └── Sources/           # کدهای سوئیفت کلاینت و رابط کاربری SwiftUI
└── android-gateway/           # گیت‌وی اندروید (Kotlin, InCallService, BLE Server)
    ├── build.gradle.kts
    └── app/src/main/
        ├── AndroidManifest.xml
        └── java/com/phonebridge/gateway/
```
